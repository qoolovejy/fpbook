설계사수첩 계정 및 데이터 삭제 안내

앱 이름: 설계사수첩 · 개발자: ryanauto

설계사수첩은 별도의 회원 계정을 만들지 않습니다. 구글 계정으로 로그인하면 데이터가 사용자 본인의 구글 드라이브 앱 전용 공간에 백업될 뿐이며, 개발자 서버에는 어떤 데이터도 저장되지 않습니다. 따라서 "계정 삭제"는 아래처럼 앱의 접근 권한을 끊고 백업을 지우는 것을 뜻합니다.

1. 앱 안에서 일부 데이터 삭제하기

  • 고객 화면 오른쪽 위 메뉴 → "고객 삭제"를 누르면 그 고객과 보험·상담 기록·일정이 함께 삭제됩니다.
  • 일정이나 상담 기록은 각 화면의 휴지통 아이콘으로 삭제합니다.
  • 전체를 지우려면 더보기 → 모든 데이터 삭제를 누르세요. 구글 로그인 상태라면 드라이브 백업에서도 함께 삭제됩니다.

2. 구글 계정 연결 해제와 백업 전체 삭제 (계정 삭제에 해당)

  1. 앱의 더보기 → 로그아웃을 누릅니다.
  2. 구글 계정 관리 페이지 https://myaccount.google.com/connections (보안 → 타사 앱 및 서비스)에서 설계사수첩을 선택하고 "설계사수첩과의 연결 삭제"를 누릅니다.
  3. 이때 "설계사수첩이 저장한 데이터 삭제" 옵션을 함께 선택하면 드라이브 앱 전용 공간의 백업이 모두 삭제됩니다.
  4. 앱을 삭제하면 기기 안의 모든 데이터도 삭제됩니다.

3. 삭제되는 데이터와 보관 기간

  • 삭제 대상: 고객 정보(이름·연락처·생년월일·주소·직장·가족·메모), 가입 보험, 일정, 상담 기록, 구글 계정 표시용 정보(이름, 이메일, 프로필 사진).
  • 개발자는 사용자 데이터를 보관하지 않으므로 별도의 보관 기간이 없습니다. 위 절차가 끝나면 남는 데이터가 없습니다.
