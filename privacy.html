설계사수첩 개인정보처리방침

시행일: 2026년 10월 14일

설계사수첩(이하 "앱")은 사용자의 개인정보와 사용자가 기록한 고객 정보를 소중히 다룹니다. 본 방침은 앱이 어떤 정보를 다루고 어떻게 보호하는지 설명합니다.

1. 수집하는 정보

앱은 개발자 서버를 운영하지 않으며, 사용자가 입력한 정보를 개발자에게 전송하지 않습니다. 광고·분석 도구를 사용하지 않습니다.

  • 고객 정보(이름, 전화번호, 이메일, 생년월일, 주소, 직장, 가족관계, 메모, 가입 보험, 일정, 상담 기록 등): 사용자가 직접 입력하거나 휴대폰 연락처에서 선택해 가져온 정보로, 사용자의 기기 안에만 저장됩니다.
  • 휴대폰 연락처: 사용자가 "연락처에서 가져오기"를 눌렀을 때만 연락처 읽기 권한을 요청하며, 사용자가 선택한 사람의 정보만 앱에 저장됩니다. 선택하지 않은 연락처는 저장하지 않습니다.
  • 구글 계정 정보(이름, 이메일, 프로필 사진): 사용자가 선택적으로 구글 로그인을 했을 때만, 앱 화면에 로그인 상태를 표시하기 위해 기기 안에서만 사용합니다.

2. 구글 드라이브 백업

사용자가 구글 로그인을 하면 앱의 모든 데이터가 사용자 본인의 구글 드라이브 앱 전용 공간(appDataFolder)에 백업되어 같은 계정의 다른 기기와 동기화됩니다. 이 공간은 사용자 본인과 앱만 접근할 수 있으며, 개발자를 포함한 제3자는 접근할 수 없습니다. 앱이 요청하는 구글 권한은 drive.appdata 하나이며, 사용자의 다른 드라이브 파일에는 접근하지 않습니다.

로그인하지 않으면 사용자가 입력한 데이터는 기기 밖으로 나가지 않습니다. 사용자가 "백업 파일 내보내기"로 만든 파일은 사용자가 고른 앱(메신저, 메일, 클라우드 등)으로 전달되며 그 이후의 처리는 해당 서비스의 정책을 따릅니다.

3. 기기 권한

  • 연락처 읽기: 휴대폰 연락처에서 고객을 가져올 때만 사용합니다.
  • 알림 / 정확한 알람: 사용자가 일정에 설정한 미리 알림과 아침 브리핑 알림을 보내기 위해 사용합니다.
  • 인터넷: 구글 드라이브 백업에만 사용합니다.
  • 전화 걸기·문자 보내기는 기기의 기본 전화·메시지 앱을 여는 방식이며, 앱이 통화 기록이나 문자 내용을 읽지 않습니다.

4. 고객 정보의 보호 책임

앱에 기록되는 고객 정보는 사용자(보험설계사)가 업무상 관리하는 제3자의 개인정보입니다. 사용자는 관련 법령(개인정보 보호법 등)에 따라 해당 정보를 적법하게 수집·이용·보관할 책임이 있으며, 기기 분실에 대비해 화면 잠금을 사용하고 불필요해진 정보는 삭제하시기 바랍니다. 앱은 해당 정보를 기기와 사용자 본인의 드라이브 외의 어디에도 전송하지 않습니다.

5. 정보의 삭제

  • 앱에서 고객·일정·기록을 삭제하면 기기에서 지워지고, 동기화 중이면 드라이브의 백업도 함께 삭제됩니다. 더보기 → "모든 데이터 삭제"로 전체를 지울 수 있습니다.
  • 앱을 삭제하면 기기의 모든 데이터가 삭제됩니다.
  • 드라이브 백업은 구글 계정 설정 → 보안 → 타사 앱 및 서비스에서 "설계사수첩"의 접근 권한을 삭제하면 함께 삭제할 수 있습니다. 자세한 절차는 계정·데이터 삭제 안내를 참고하세요.

6. 제3자 제공

앱은 사용자가 입력한 정보를 제3자에게 제공하거나 판매하지 않으며, 광고·분석 도구를 사용하지 않습니다.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 방침의 변경

본 방침이 바뀌면 앱 업데이트 안내 또는 이 페이지를 통해 알립니다.
